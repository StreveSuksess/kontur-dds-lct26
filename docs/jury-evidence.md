# Доказательства по критериям жюри

Источник критериев — предоставленное PDF «9. Деп Обороны и ЧС», разделы 16–18 (физические страницы 18–20). В нём нет числовых весов; учебные 100 баллов внутри продукта не являются конкурсной оценкой. Telegram Q&A уточняет дедлайн и формат подачи, но не добавляет весов ([журнал сообщений](../memory-bank/research/2026-09-28-chat-qa-audit.md)). «Проверено» ниже означает указанную техническую проверку, не приёмку учебным центром.
