# Локальная установка классификатора

Публичный исходный код содержит `backend/data/classifier.json` только как пустой маркер. Оригинальная таблица заказчика и её полная нормализованная копия не распространяются через публичный Git. Восемь синтетических заданий из `backend/data/scenarios.json` продолжают работать. Поиск по справочнику и генерация черновика из выбранного кода требуют локального импорта.

Если у вас есть законный доступ к **поддерживаемой схеме v046_11**, сохраните исходный `.xlsx` вне публичного репозитория и выполните из корня проекта:

```sh
python3 scripts/import_classifier.py /путь/к/вашему/classifier-v046_11.xlsx --output backend/data/classifier.json
```

Импортёр проверяет опорные заголовки и границы колонок, сохраняет источник строк и условные поля маршрутизации. Изменённую схему, включая v046_24, он отклоняет до записи файла; её нельзя просто переименовать. После успешного импорта держите `backend/data/classifier.json` только в разрешённом локальном контуре и не добавляйте его в публичные коммиты. Методист должен проверить использование кодов, особенно неоднозначные маршруты и исключённую по задаче пожарную группу. Автоматический импорт не подтверждает правильность назначения служб.
