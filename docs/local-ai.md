# Проверенный локальный AI и голос

В рабочем каталоге реально запущены два независимых локальных сервиса. Ни один не вызывает облачный inference. Исходящие реплики подготовлены локальным `say` и воспроизводятся как WAV. Это исходящий доклад диспетчера ДДС по готовой карточке; звонок гражданина не моделируется.

## Запущенные адреса и команды

| Компонент | Адрес | Проверка |
|---|---|---|
| Qwen3 1.7B, llama-server | `http://127.0.0.1:11434` | `GET /health`, `GET /v1/models` |
| Whisper small, CPU | `http://127.0.0.1:11435` | `GET /health` |

Из корня репозитория в отдельных процессах:

```sh
scripts/local_ai/start.sh
scripts/local_ai/start_speech.sh
```

Текущий интерпретатор ASR: `./research/.venv-asr/bin/python`. Контрольная точка: `research/models/openai/small.pt`. Для новой установки пути можно переопределить:

```sh
LOCAL_AI_PYTHON=runtime/local-ai/venv/bin/python \
WHISPER_MODEL_PATH=models/local-ai/whisper-small.pt \
scripts/local_ai/start_speech.sh
```

`setup.sh` описывает воспроизводимую установку **для macOS arm64** внутри workspace. Нужны `uv`, `curl`, `git`, `shasum`, около 12 ГБ свободного места для исходных и промежуточных файлов. В текущем окружении этапы выполнены по отдельности и проверены; повторный полный прогон установщика с чистого каталога не выполнялся. Не запускать установщик параллельно работающему Python: установка меняет зависимости виртуального окружения. Linux/x86 и закрытая сеть заказчика требуют отдельно подготовленного пакета, их работоспособность здесь не заявляется.

```sh
scripts/local_ai/setup.sh
```

## LLM API и границы применения

Реальная модель: официальный QwenLM `qwen-lm/qwen-3/transformers/1.7b/1`, преобразованный из safetensors в GGUF и Q4_K_M. Размер итогового файла около 1,28 ГБ; метаданные llama-server показывают 2 031 739 904 параметра, название публикации — 1.7B. Alias API: `qwen3-1.7b`. Запуск CPU, четыре потока, GPU layers=0, контекст 4096, один слот. Это не измерение на i5/16 ГБ из задания: машина разработки Apple arm64, 48 ГБ.

```sh
curl http://127.0.0.1:11434/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -d '{"model":"qwen3-1.7b","messages":[{"role":"user","content":"Верни JSON с ключом greeting и коротким приветствием по-русски."}],"temperature":0,"max_tokens":512,"stream":false,"response_format":{"type":"json_object"},"chat_template_kwargs":{"enable_thinking":false}}'
```

Сервер поддерживает JSON-объект, температуру, `max_tokens` и `chat_template_kwargs.enable_thinking`. Формат JSON **не гарантирует смысловую правильность**. `scripts/local_ai/client.py` проверяет типы, точные подстроки доказательств и неизменность эталонных фактов при генерации. Невалидный ответ, обрезание по токенам или недоступный сервис возвращают `available:false`, `mode:unavailable`, `result:null` и причину; отсутствующий AI не выдаётся за работающий.

`generate(facts, instructions)` создаёт только учебную формулировку: `title`, `description`, `objective`, точная копия `facts`. Преподаватель утверждает результат. `analyze(text, facts)` — **экспериментальная диагностическая функция**, не автоматическая оценка и не основание менять баллы. Для неё включено reasoning, для генерации формулировок отключено. Содержимое внутреннего reasoning в пользовательский результат и отчёт проверки не сохраняется.

Первые два варианта промпта без reasoning дали лишь 2/6 и 1/6 правильных ответов на шесть синтетических проверок: модель переносила адрес из эталона в доклад и путала близкие названия улиц. Все результаты сохранены, включая ошибки. Это прямое основание для правил, проверки цитат и ручного подтверждения, а не заявления об AI-точности. Включение reasoning улучшило результат до 3/6 при 4,8–7,5 секунды на запрос, но этого также недостаточно для оценивания. Текущий прогон и задержки находятся в `docs/local-ai-validation.json`; прежние в `docs/local-ai-validation-initial.json` и `docs/local-ai-validation-prompt-v2.json`. Даже успешные шесть примеров не являются независимым тестовым набором или оценкой точности на реальных докладах.

Узкий промпт из `scripts/local_ai/evaluate_generation.py` прошёл три проверки (водопровод, дерево, электроснабжение) на сохранение адреса и каждого факта. Он возвращает только `title`, `card_description`, `contact_reply`; задержки 2,955 / 1,255 / 1,258 секунды. Полный промпт и ответы находятся в `docs/local-ai-generation-validation.json`. Это небольшой набор для настройки, не доказательство качества на произвольных сценариях.

```sh
research/.venv-asr/bin/python scripts/local_ai/evaluate.py
```

## Speech API

```sh
curl http://127.0.0.1:11435/transcribe \
  -H 'Content-Type: audio/wav' \
  --data-binary @frontend/public/audio/duty_greeting.wav
```

Дополнительно проверен WebM/Opus: тот же синтетический доклад распознан за 1,958 секунды с сохранением адреса и отрицания.

Тело — **raw bytes**, не multipart. Поддерживаемые Content-Type: `audio/wav`, `audio/x-wav`, `audio/webm`, `audio/ogg`, `audio/mp4`, `application/octet-stream`. PyAV декодирует в mono 16 kHz; Whisper запускается с фиксированным русским языком. Ограничение 10 МиБ и 120 секунд; код 413 при превышении, 415 при неподдерживаемом MIME, 400 при неверном аудио, 429 при занятом единственном ASR-слоте. Вызовы из браузера следует направлять через backend proxy; сервис не публикует CORS и привязан к loopback.

```json
{"text":"Дежурный на связи, слушаю ваш доклад.","language":"ru","duration_seconds":2.696,"latency_seconds":1.021,"model":"whisper-small","mode":"local_asr","requires_human_review":true,"segments":[{"start":0,"end":2.64,"text":" Дежурный на связи, слушаю ваш доклад."}]}
```

Четыре WAV из демо распознаны с сохранением слов за 0,8–1,0 секунды на данном компьютере. Дополнительный синтетический доклад 9,724 секунды обработан за 2,763 секунды с сохранением адреса «Дубнинская улица» и отрицания «пока не направлена». Это синтетические чистые реплики, а не оценка качества живой речи, телефонного канала, акцентов или числа параллельных обучающихся. Тишина возвращает пустой текст. Адреса, номера и отрицания обязательно показывать пользователю для проверки; нельзя молча заменять распознанный адрес эталонным.

## Голосовые файлы

`frontend/public/audio/manifest.json` содержит тексты, длительности и метаданные. Подготовлены `duty_greeting.wav`, `supervisor_greeting.wav`, `report_ack.wav`, `repeat_request.wav`: PCM16 mono 22050 Hz. Единственный установленный русский голос — Milena. Два разных пола не реализованы. Динамическая озвучка полных произвольных реплик теперь доступна через отдельный локальный TTS-сервис: [local-tts.md](local-tts.md). Перегенерация на Mac: `python3 scripts/local_ai/generate_audio.py`. Это записи ответов тренажёра, не доказательство SIP-интеграции; реальный РТУ/IP-телефон не проверялся.

## Происхождение и воспроизводимость

- [Официальный релиз Ollama 0.34.2](https://github.com/ollama/ollama/releases/tag/v0.34.2): standalone Darwin archive. Используется вложенный **llama-server**, версия `0.4.1-dev`, build 1, commit `391fac164`. Сам `ollama serve` не запускался: он создаёт ключ в домашнем каталоге, а задача требует workspace-only runtime.
- SHA256 архива: `f33b2a5aa59bc6c961ed3ec23ba9dc646ca6d99ced8d2a0d46eb3a522167dd3f`, проверен по checksum релиза.
- [Публикация QwenLM в Kaggle](https://www.kaggle.com/models/qwen-lm/qwen-3/Transformers/1.7b). HF, Ollama registry и ModelScope были недоступны в данном сетевом окружении; доступ не обходился. Независимая официальная публикация Kaggle доступна. Whole-bundle download вернул ошибку на необязательном файле; необходимые веса, tokenizer и config скачаны, конвертер успешно их прочёл.
- [Официальный конвертер llama.cpp](https://github.com/ggml-org/llama.cpp), commit `2b1847030cef76ef315eaee0b7ae0cdcd4fb15ff`; quantizer из проверенного архива. SHA256 Q4_K_M: `34806af251388657913cabb4c5289e85f252979437cd3049374fae22faab99ae`.
- [OpenAI Whisper](https://github.com/openai/whisper): `openai-whisper==20250625`, small weights из официального AzureEdge; SHA256 `9ecf779972d90ba49c06d968637d720dd632c55bbf19d441fb42bf17a411e794` проверен. `torch==2.14.0`, `av==18.1.0`.
- Runtime, исходные веса и модели исключены из Git. При переносе в закрытый контур нужны сами бинарные артефакты, лицензии/NOTICE исходных проектов и проверки на целевой машине, а не только этот репозиторий.

### Ограничение после живой проверки интерфейса

Qwen3-1.7B дал ложные замечания на правильный адрес и роль докладчика в завершённой попытке. Поэтому AI-review скрыт в свёрнутом экспериментальном разделе и запрашивается только для спорных смысловых/языковых критериев (`review`, content/grammar). Если таких критериев нет, endpoint возвращает пояснение без вызова модели. Точность цитаты не гарантирует верность вывода. Основной разбор и оценку это не меняет. Подробности: [браузерный протокол](ui-validation.md).
