## Запуск актуального кода

Из корня репозитория: `./scripts/start.sh`. Нужны Python 3.12 или 3.13, `uv`, Node.js 22 и npm; на первом запуске зависимости скачиваются. После сборки открыть `http://127.0.0.1:8000`. Для локального синтетического режима: преподаватель `teacher`, учащийся `student`, пароль `Demo112!`. Этот пароль публичен и не предназначен для рабочего контура. Серверный AI необязателен: базовый сценарий, учебный телефон и оценивание правилами работают без него.

1. Преподавателем открыть «Сценарии», просмотреть и назначить утверждённый сценарий.
2. Учащимся открыть назначение. Таймеры фиксируют 30 секунд до открытия карточки и 3 минуты до первого сохранённого статуса с текстом; дальнейшие статусы не имеют этого трёхминутного лимита.
3. Провести учебный исходящий разговор, зафиксировать статусы и сдать попытку.
4. Преподавателем открыть отчёт: событийные доказательства, исходную оценку, решение по критериям и общий подтверждённый итог.
5. Отдельно открыть «Первичный приём 112»: учащийся заполняет карточку по текстовой вводной, выбирает службы, преподаватель видит сравнение и сохраняет заключение.

Пошаговые реплики — в [сценарии показа](demo-script.md), API — в [контракте](api-contract.md). Данные синтетические; реальные вызовы и службы не подключены. Прямая публичная URL-адресация сервера пока не подтверждена, поэтому эту страницу нельзя выдавать за hosted live demo.
