# Озвученная видеопрезентация RC4

[MP4](../deliverables/kontur-dds-demo-v4.mp4) длится **3:55,29** (1920×1080, H.264/AAC, 24 кадра/с), что укладывается в лимит пяти минут. Это **монтаж реальных экранов прототипа и слайдов**, а не непрерывный скринкаст одной попытки. Озвучка синтезирована локальным голосом macOS Milena ru_RU; в кадре нет реальных операторов или результатов учебного пилота. Подпись о монтаже видна на протяжении ролика, а каждый кадр отдельно помечен как схема или снимок.

## Источники и смысл кадров

Покадровый протокол глав, длительности, текст озвучки, SHA-256 каждого исходного файла и точные параметры кадрирования записаны в [машинном протоколе](demo-video-v4-validation.json). Слайды взяты из [v3 PDF](../deliverables/kontur-dds-defense-v3.pdf). Свежие экраны 112 и очереди сняты через CUA из браузерного RC4 прототипа в публичном checkout; файлы источников сохранены без изменений. Их фрагменты кадрированы FFmpeg только для читаемости. Показанная заполненная учеником форма 112 снята **до отправки**; соседний преподавательский экран иллюстрирует **отдельное сохранённое состояние разбора**. Монтаж не утверждает, что это непрерывная запись одной попытки.

Браузерная проверка 112 с результатом 7/9 точных совпадений, двумя свободными полями на проверку и сохранённым преподавателем заключением записана в [проверке публичной поставки](public-release-smoke.md). Это проверка функции на синтетической карточке, а не методистская оценка. Очередь ДДС показана на двух свежих браузерных кадрах: две одновременно поступившие карточки с отдельными часами и вид ожидающей карточки из рабочего места. Эти снимки подтверждают видимое состояние интерфейса, а не длительную нагрузку живого класса. Синтетический набор оценщика покрыт на 28/48 утверждений, 27 из 28 поддержанных совпали с авторской разметкой. Реальных учебных данных и пилота нет. Официальное соответствие шаблону ЛЦТ не достигнуто: исходные слайды шаблона 7–11 недоступны.

## Воспроизведение и проверка

Скрипт [demo_video_v4.py](../scripts/demo_video_v4.py) строит MP4 из версионированного v3 PDF и шести перечисленных PNG. Нужны подготовленный Python с `imageio-ffmpeg`, Poppler `pdftoppm`, macOS `say` с голосом Milena ru_RU и установленный Arial. Скрипт не скачивает зависимости и не обращается к браузеру. Команда для текущей среды:

```bash
research/.venv-asr/bin/python scripts/demo_video_v4.py
```

Скрипт создаёт временные WAV/MP4 и один PNG инспекции на главу в `runtime/demo-video-v4/`, останавливается при длительности свыше пяти минут, полностью декодирует итоговый файл FFmpeg и записывает [протокол](demo-video-v4-validation.json). В финальном прогоне полный decode прошёл без ошибок. Просмотрены все 12 PNG инспекции: подписи видимы, схемы отделены от экранов, поля и цифры не обрезаны. Контроль звука: AAC mono 48 кГц, средний уровень −17,2 dB, пик −2,1 dB, 11 308 032 декодированных аудиосэмпла. Прослушивание человеком и проверка в целевом зале не проводились.

SHA-256 финального MP4: `a2f095b9004fa675449de952465c5cca8c3b154c3bc0501927ebd38e8d5877b3`. Размер: 6 258 051 байт. RC1 MP4 сохранён без изменений.
