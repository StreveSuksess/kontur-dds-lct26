# Публичная копия без производного классификатора

## Context

Письменное ТЗ требует открытый репозиторий. Рабочая история и прежний приватный GitHub-снимок содержат JSON, производный от таблицы заказчика. Права на публичное распространение этой таблицы не установлены; перевод прежнего репозитория в public сохранил бы данные в истории.

## Decision

Создать новый публичный репозиторий `StreveSuksess/kontur-dds-lct26` с чистой историей из проверенного allowlist-снимка исходников; заменить `backend/data/classifier.json` явным пустым маркером `metadata.redacted=true`. Не переносить манифест полного приватного ZIP. Добавить инструкцию локального импорта исходной таблицы и проверить приложение с пустым классификатором.

## Alternatives

Открыть прежний приватный репозиторий: отвергнуто из-за истории полного классификатора. Оставить репозиторий закрытым: не даёт гостевой ссылки жюри. Публиковать полный source ZIP: отвергнуто по той же причине. Создать фиктивный классификатор с изменёнными кодами: может создать ложное впечатление нормативной пригодности.

## Consequences

Код, синтетические сценарии и демонстрация доступны без авторизации; поиск/генерация на основе классификатора не работает до локального импорта. Интеграционный тест отдельно проверяет честный ответ 404 в публичной копии. Внешние проверки формата на содержимом реального классификатора воспроизводятся только владельцем исходной таблицы.
