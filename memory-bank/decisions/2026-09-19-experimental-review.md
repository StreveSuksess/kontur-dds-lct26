# Экспериментальные замечания модели

## Context
Локальный Qwen3-1.7B дал3/6 корректных ответов на малом семантическом smoke. Живой браузерный разбор корректной попытки19.09 показал ложные замечания: одинаковый адрес назван неполным; «Докладывает диспетчер» ошибочно трактуется как неправильный адресат. Проверка дословности цитаты не доказывает верность вывода.

## Decision
Не предлагать AI-разбор как основной путь преподавателя. Раздел свёрнут и явно назван экспериментальным. Сервер вызывает модель только для content/grammar-критериев со статусомreview; для формальных, pass и fail критериев модель не запрашивается. Баллы неизменяемы; доказательные event-based правила и экспертное решение остаются основой.

## Alternatives
Показывать все предложения с общей оговоркой — уже создаёт лишнюю работу на корректных докладах. Увеличить модель — непроверенная скорость и память целевого CPU. Полностью удалить модуль — теряет исследовательский инструмент, хотя API-границы и citation filtering полезны для будущей модели.

## Consequences
Экспериментальные замечания не заявляются доказанной экономией времени. Ограничение уменьшает область ложных советов, не валидирует качество внутри неё. Перед включением по умолчанию нужен методистский benchmark и пилот. Генерация3полей/ASR сохраняют отдельные измерения и ручное подтверждение.
