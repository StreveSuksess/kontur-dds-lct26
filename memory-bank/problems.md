## Экспертная проверка — RC2кандидат
RC2 реализует точечную проверку с основанием, ревизией и повторным общим подтверждением. Технически проверено 128 backend/28 stdlib/13 Node + build, браузерным путём, включая два параллельных черновика в одной странице, и финальным архивным smoke. Это продуктовая гипотеза, пользовательски не подтверждена: время разбора, удобство и согласие методистов не измерены.

## Совпадение следующего упражнения — fixed / границы
RC3 устраняет выдачу сценария без требуемого повторяющегося критерия и объясняет подбор. Строгое ID+label совпадение может пропустить семантически эквивалентный иначе названный критерий; смысловая эквивалентность и равная сложность не доказаны. Первые5 предложений не исчерпывают библиотеку, UI теперь это явно обозначает. Массовый выбор группы и прямое назначение из рекомендации остаются продуктовым backlog.
