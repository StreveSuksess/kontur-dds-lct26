# Контур ДДС — материалы защиты

Актуальный набор: [презентация PPTX](kontur-dds-defense-v3.pptx) и [PDF](kontur-dds-defense-v3.pdf), [сопроводительная документация PDF](kontur-dds-documentation-v3.pdf), [страница проверки прототипа](../docs/prototype.md) и [код](https://github.com/StreveSuksess/kontur-dds-lct26). Исходный ZIP `kontur-dds-source-rc5.zip` собирается и проверяется локально; его SHA-256 и состав записаны в соседних `.validation.json`/`.manifest.json`. ZIP содержит полный производный классификатор и **не предназначен для открытой публикации**.

`kontur-dds-demo-v4.mp4` — актуальный озвученный монтаж RC4 (3:55) с реальными кадрами 112 и очереди ДДС; это не непрерывный скринкаст и не пилот. Происхождение и проверка — [протокол](../docs/demo-video-v4.md). Прежний `kontur-dds-demo-montage.mp4` (RC1, 3:56) сохранён исторически. Презентация v3 авторская: соответствие официальному шаблону из Telegram №782 не подтверждено, поскольку шаблон не содержался в предоставленной выгрузке. RC4 прошёл техническую регрессию, но не методистский пилот, проверку на целевом i5/Linux или живом VoIP. Точные ограничения — [матрица жюри](../docs/jury-evidence.md).

Предыдущие v1/v2 и offline RC2 сохранены как замороженные исторические артефакты. Проверка offline RC2 не переносится на RC4. Для подачи используются четыре публичные ссылки из [инструкции](../docs/submission-handoff.md).
