# Контур ДДС — материалы защиты

Актуальная версия RC4: [презентация PPTX](kontur-dds-defense-v3.pptx) и [PDF](kontur-dds-defense-v3.pdf), [сопроводительная документация PDF](kontur-dds-documentation-v3.pdf), [страница проверки прототипа](../docs/prototype.md) и [код](https://github.com/StreveSuksess/kontur-dds-lct26). Исходный ZIP `kontur-dds-source-rc4.zip` собран и проверен локально; его SHA-256 и состав записаны в соседних `.validation.json`/`.manifest.json`. ZIP содержит полный производный классификатор и **не предназначен для открытой публикации**.

`kontur-dds-demo-montage.mp4` — озвученный монтаж RC1 (3:56), а не непрерывная запись текущего RC4. Презентация v3 авторская: соответствие официальному шаблону из Telegram №782 не подтверждено, поскольку шаблон не содержался в предоставленной выгрузке. RC4 прошёл техническую регрессию, но не методистский пилот, проверку на целевом i5/Linux или живом VoIP. Точные ограничения — [матрица жюри](../docs/jury-evidence.md).

Предыдущие v1/v2 и offline RC2 сохранены как замороженные исторические артефакты. Проверка offline RC2 не переносится на RC4. Для подачи используются четыре публичные ссылки из [инструкции](../docs/submission-handoff.md).
